Marisol Bay is a sun-soaked open-world crime game: drive and walk a golden-hour coastal city, steal cars, dodge a 5-star wanted level with police chases and a helicopter, fight rivals, run 8 story missions for Dario Cole and his crew, and tune in to three original synth radio stations. Built with Three.js, fully offline, keyboard + mouse.

## Run it

```sh
node serve.ts
```
